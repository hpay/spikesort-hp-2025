# spikesort-hp-2025
My wrapper code for spike sorting with kilosort

This includes the copy of the kilosort2.0 repo that was used for spike sorting in Payne & Aronov 2025

## Instructions

First follow instructions on the kilosort2.0 github page to install kilosort 2.0

Then run the built-in kilosort gui (kilosort.m in in the kilosort2.0 folder) to check kilosort installation

Then navigate to the spikesort-hp\scripts folder and: 
- runBatchKilosort.m to run kilo2.0 on a bunch of files in matlab using slightly custom settings
